# Project Name: Agentic AI Workflow Orchestration
**Role:** AI Architect
**Tech Stack:** n8n, LangChain, CrewAI, OpenAI API, Python.

## Description
Architecting the "Invisible Engine" for enterprise operations—moving from simple chatbots to autonomous agents that can execute business processes.

## Key Technical Achievements
- **Autonomous Agents:** Constructed pipelines where AI agents autonomously plan tasks, call APIs, perform web lookups, and execute data transformations.
- **Self-Correction:** Implemented memory slots and multi-step reasoning loops, allowing the agents to "self-correct" if a step fails.
- **Email Automation:** Created an end-to-end n8n workflow that reads emails, classifies leads, extracts contact info, and auto-assigns CRM actions based on priority.
